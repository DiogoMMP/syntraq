# raw/

Untouched source material: articles, papers, repos, datasets, images — anything you index for the LLM to read. Drop things in here as-is (e.g. via the Obsidian Web Clipper, `git clone`, downloaded PDFs, exported datasets).

Organise it however you like — there is no required folder structure or naming convention; skills work out what each file is from its path, name and content.

This folder is never edited by the LLM — only read from. If a source changes, replace or version it explicitly; don't let the compilation step rewrite it.
